# 컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기

## 프로젝트 소개
Codyssey 미션 2에서 Python을 활용하여 콘솔 기반 퀴즈 게임을 개발합니다.

## 퀴즈 주제
항공우주 기초 지식

## 개발 환경
- Ubuntu 24.04.4 LTS (WSL2)
- Python 3.12.3
- Git 2.43.0

## 구현 예정 기능
- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 확인
- 최고 점수 확인
- 게임 종료
- JSON 파일을 통한 데이터 저장 및 불러오기

## 실행 방법
개발 완료 후 다음 명령어로 실행합니다.

    python3 main.py

## 개발 상태
프로젝트 초기 설정
